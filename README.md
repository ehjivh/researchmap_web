# 研究業績一覧

ResearchmapからエクスポートしたJSON / JSONLデータを、ブラウザ上で閲覧するための軽量なオフラインビューアです。

Researchmapにアクセスできない場合でも、手元のエクスポートデータから研究者情報・経歴・業績を確認できます。

## 使い方

1. [index.html](./index.html) をブラウザで開きます。
2. 「JSON / JSONLをアップロード」をクリックします。
3. Researchmapからエクスポートしたファイルを選択します。
4. 読み込まれた研究者情報が画面に表示されます。

アップロード前は個人情報や業績情報を表示しません。ファイルをアップロードした後に、そのファイルに含まれる情報だけが表示されます。

## 対応している主な項目

Researchmapのエクスポートデータに含まれるレコードを、以下の章に分けて表示します。

1. 基本情報
2. 研究キーワード
3. 研究分野
4. 経歴
5. 学歴
6. 委員歴
7. 受賞
8. 論文
9. その他の業績（`misc`）
10. 講演・口頭発表等
11. 所属学協会
12. 社会貢献活動
13. メディア報道
14. その他

音楽、作曲、演奏などに該当するレコードが含まれている場合は、音楽活動として表示します。

## 引用形式

論文・書籍等出版物・講演・口頭発表等・`misc`・メディア報道では、各項目の「引用形式を表示」から以下を確認できます。

- APA形式
- BibTeX形式
- 引用のコピー

共著の場合は、エクスポートデータの `authors` に含まれる全著者を表示します。講演・口頭発表等では `presenters` に含まれる全発表者を表示します。

## 検索

画面上部の検索欄から、表示中のプロフィール内を検索できます。

氏名、研究分野、研究キーワード、タイトル、所属、開催情報などを検索対象にしています。

## 対応ファイル形式

- JSON配列
- 単一のJSONオブジェクト
- JSONオブジェクトが連続するResearchmapエクスポート形式
- JSONL形式

## 個人情報について

このビューアは、アップロードされたファイルを外部サーバーへ送信しません。ブラウザ内でファイルを読み込み、画面上に表示します。

ただし、アップロードしたJSONに含まれる情報は画面に表示される可能性があります。一般公開する場合は、公開してよいデータだけを含むファイルを使用してください。

連絡先などの機微な情報は、現在の画面表示では基本情報として表示しない設計です。ただし、業績の説明文や自由記述欄に含まれる情報までは自動的に除去しないため、公開前にJSONの内容を確認してください。

## ファイル構成

```text
researchmap_web/
├─ index.html
├─ styles.css
├─ app.js
└─ README.md
```

- `index.html`: 画面の構造
- `styles.css`: 表示スタイル
- `app.js`: JSON読み込み、分類、検索、引用生成

## 注意事項

- 引用形式は、エクスポートデータに含まれる著者名・タイトル・刊行物名などをもとに生成する簡易形式です。
- 投稿規程や機関指定の書式に合わせる場合は、生成された引用を確認・調整してください。
- 現在のビューアは、Researchmapの公式画面や公式APIを再現するものではありません。
- 外部リンクを開く場合は、リンク先の公開範囲と安全性を確認してください。
